# المراجعة الأمنية — موقع إخباري (Laravel 13)

تاريخ المراجعة: 2026-10-12 — م,state إنتاجية: https://arllm.dev (Hostinger Business / PHP 8.4)

## 1) الإجراءات الأمنية المطبقة (حاليًا في الكود)

| المجلّد | الحالة |
|---|---|
| **علاقات قواعد بيانات** | PDO + Prepared statements عبر Eloquent — لا استعلامات ملف من مدخلات المستخدم |
| **CSRF** | مُفعّل على كل النماذج (middleware web) + module @json |
| **XSS** | محتوى المقالات عبر CommonMark مع `html_input: strip` + `allow_unsafe_links: false`؛ تعليقات الزوار عبر `strip_tags` |
| **كشف كلمات مرور** | bcrypt (rounds=12) ويم assignment على الموديل |
| **تقييد المعدل** | تسجيل دخول 5/د/مستخدم، تعليقات 3/د/IP، لوحة إدارية 60/د، AI 12/د |
| **رأس الحماية (Headers)** | CSP (لإزالة أي سكربت خارجي)، X-Frame-Options DENY، nosniff، HSTS 1 سنوية بادخال النطاقات الفرعية، إزالة X-Powered-By |
| **HTTPS** | مفروض عبر Hostinger + `SESSION_SECURE_COOKIE=true` + نفس الجلسة HttpOnly + SameSite=Lax |
| **التسجيل العام** | معطّل — الحسابات تُنشأ من اللوحة (المدير فقط) |
| **الحماية من الحذف الأخير** | لا يمكن حذف آخر مدير؛ حقل تنشر كلمات المستخدم عند حذفه |
| **رفع الملفات** | قائمة امتدادات مُغلقة، وسقف أحجام، أسماء عشوائية غير انعكسية + SVG مُنقّى (سكربر للأحداث)` |
| **Privacy injection** | لا تفسش وسم `csrf-token` خارج التطبيقات المطلوبة |
| **كاش إعدادات عامة** | .env خارج docroot تمامًا (public_html يحوي index.php فقط) |
| **مفاتيح ثالثة** | API key AI مشفّرة AES-256-GCM ولا تُعاد للواجهة (مُقنّعة) |
| **تقييد أدوار** | Gates لكل شاشة إدارية (admin/editor/author) + سياسات على مستوى الموديل |

## 3) ما يُنصح بفعله دوريًا (مراجعة مستقبلية)

### عمارة حساسة (يجب تداولها):
- **كلمة مرور قاعدة البيانات**: استبدلها من hPanel كل 3-6 أشهر (توليد عشوائي 24 حرفًا)
- **APP_KEY**: لا ت participación في أي مكان إذا استقرت الملفات — إعادة توليدها تفسد الوسائط المشفرة فقط (في AI)
- **GitHub PAT**: أبطل أي توكن بارز عندك بعدétablissement并将ه بجديد ص nilت运 محدود `Contents: RM several workflow`
- **مفتاح SSH**: عند مراقَ الحساب، احذف القديم وحدد عامًا مرتبطًا بجهاز واحد

### إضادات إدارية:
- تحقق من نسخة PHP في hPanel كل فترة (اقترح 8.5 الآن)
- فعّل **النسخ الاحتياطي التلقائي** من hPanel (قاعدة + ملفات) على وجه محدد
- ادخل على GitHub ← Settings ← Action: راجع صلاحية GITHUB_TOKEN (Read/Write) لتوفير JIT anew

### مسار خطوات مستقبلية:
1. **2FA** على حساب GitHub وحساب المدير (الطلبات المست日制 أو فئة محدودة)
2. إضافة مصلك الذيار لفتح التيكيتات على النشرة عبر إيميل دعم بدل التعليقات الحرّة
3. CDN حماية DDoS (Hostinger يملك)، أو Cloudflare مجانًا، وقيود IP على لوحة `/admin` إن أمكن
